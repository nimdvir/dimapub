# data-source

תיקייה לקבצי עבודה: מסמכים, טיוטות, נתונים, מחקרי שוק, קבצי מקור לתמונות וכו'.

**שום דבר כאן לא נכלל באתר.** האתר נבנה רק מהתיקיות `src/` ו-`public/`,
כך שקבצים בתיקייה הזו לא יופיעו ב-dimapub.com ולא ישפיעו על הבנייה.

## חשוב לדעת

- **הריפו ציבורי.** כל קובץ שנשמר כאן גלוי לכל מי שנכנס ל-github.com/nimdvir/dimapub.
  אל תשמור כאן מידע רגיש (חוזים, מחירים פנימיים, מחקרי שוק חסויים, סיסמאות או מפתחות).
  לחומרים חסויים השתמש ב-bucket הפרטי `research` ב-Supabase (פורטל השותפים), או הפוך את הריפו לפרטי.
- GitHub חוסם קבצים מעל 100MB, ומזהיר על קבצים מעל 50MB.
- אפשר ליצור תת-תיקיות כרצונך, למשל `research/`, `drafts/`, `images/`.
